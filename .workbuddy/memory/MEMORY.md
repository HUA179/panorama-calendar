# 个人全景日历项目约定

- 采用五个独立 ICS 订阅：全国假期（iOS 红色）、广西假期（绿色）、国家纪念日、F1 赛历（黑色）、F1 战报。
- F1 仅收录排位赛、冲刺排位赛、冲刺赛、正赛；排除练习赛和季前测试。赛历与战报独立修订，保留发车顺位与最终排名。
- 调休上班为独立全天事件，使用 `TRIGGER;RELATED=START:-PT4H` 实现前一晚 20:00 提醒；需 iOS 真机验收。
- 纪念日仅收录国家正式设立且有明确日期的项目；地方活动不收录、不标放假、不提醒。
- 全国与广西假期不预测未公布年份，不跨订阅去重；全国假期/广西假期禁止永久 RRULE。
- 技术方案文档：`个人全景日历-技术设计方案.md`。参考架构为 Python 批处理、云端定时任务、对象存储静态 HTTPS 订阅。
- F1 赛历从官方分站页 JSON-LD 读取，身份固定为 `season + event_id + session_kind`；新增分站必须先补 `data/f1_circuits.json` 的 IANA 时区，缺映射直接失败。
- 官方页面缺时刻、状态未知、缺排位/正赛数据时 fail closed；Jolpica 只做可选校验，不得顶替官方来源。
